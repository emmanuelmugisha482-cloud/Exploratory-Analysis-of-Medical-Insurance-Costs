# Exploratory Analysis of Medical Insurance Costs

## Project Overview
This project presents an interactive Excel dashboard designed to analyze medical insurance costs.
The dashboard allows users to explore key cost drivers using pivot tables and slicers.

## Tools Used
- Microsoft Excel

## Skills Demonstrated
- Data cleaning
- Pivot Tables
- Slicers
- Dashboard design
- Exploratory Data Analysis (EDA)

## Project Structure
- Dashboard: Interactive summary with KPIs and charts
- Pivot_Analysis: Data analysis using pivot tables
- Dataset: Raw data (protected)

## How to Use
1. Open the Excel file
2. Use slicers to filter the data
3. Navigate through the dashboard using buttons
4. Insights update automatically
